# cleandns

Небольшая программа для Windows, которая не дает DNS выдавать адреса из подсетей, заблокированных провайдером на порту 443.

Сделана для PUBG: игра зависает на заставке с серым дымом, когда страница лобби `prod-live-front.playbattlegrounds.com` резолвится в площадку CloudFront `108.156.22.0/24`, до которой из России не проходят HTTPS-соединения. cleandns подбирает для таких имен адреса, которые работают.

Кроме того, cleandns умеет обходить обрыв UDP, из-за которого игра зависает при входе в матч на серверах AWS во Франкфурте (см. [Обход обрыва UDP в матчах](#обход-обрыва-udp-в-матчах)).

## Скачать

[cleandns.exe](https://github.com/dhlebin/cleandns/releases/latest/download/cleandns.exe) - последняя версия из раздела [Releases](https://github.com/dhlebin/cleandns/releases).

## Как пользоваться

1. Положите `cleandns.exe` в отдельную папку: рядом с ним появятся файлы настроек и лога.
2. Запустите и разрешите запуск от имени администратора: без этого Windows не дает менять DNS.
3. В трее появится кружок (может быть спрятан под стрелкой). Серый - фильтр выключен, зеленый - включен. При первом запуске фильтр включается сам.
4. Левый клик по кружку включает и выключает фильтр. Правый клик - меню: "Включить" или "Выключить", "Запускать при входе в Windows", "Настройки", "Открыть лог", "Выход".
5. При первом запуске cleandns спросит, запускать ли его при входе в Windows. Ответ можно поменять галочкой "Запускать при входе в Windows" в меню. Автозапуск идет через планировщик заданий, поэтому окна с запросом прав администратора при входе не будет.

При включении cleandns запоминает настройки DNS каждого подключенного сетевого адаптера и ставит DNS `127.0.0.1` (сам cleandns), а вторым - прежний DNS адаптера. Если программа закроется аварийно, Windows сама перейдет на второй DNS, и интернет не пропадет. При выключении и при выходе прежние настройки возвращаются как были. Если программу закрыли включенной, при следующем запуске она включится сама.

## Как это работает

- Запросы к доменам из списка (по умолчанию `playbattlegrounds.com` со всеми поддоменами) отправляются одновременно в выбранные DNS-серверы (по умолчанию Яндекс DoT и Quad9 DoH).
- Из ответов убираются адреса из заблокированных подсетей, и возвращается первый ответ, в котором адреса остались.
- Если все выбранные серверы вернули только заблокированные адреса, запрос повторяется в запасных серверах (`fallback_dns`). Если и там нет чистого ответа, отдается последний чистый ответ для этого имени, а если нет и его - обычный ответ, так что хуже, чем без программы, не становится.
- Все остальные запросы идут в DNS вашей сети (роутер или провайдер) без изменений.
- Самообучение: cleandns проверяет подсети из ответов для доменов из списка и запоминает те, где соединение на порт 443 открывается, но сервер не присылает ни одного байта. Рабочие подсети перепроверяются через 10 минут, поэтому новая блокировка замечается быстро. Найденные блокировки хранятся в `cleandns-state.txt` и снимаются только тогда, когда перепроверка (раз в 6 часов) покажет, что подсеть снова работает.

## Обход обрыва UDP в матчах

Вторая проблема PUBG - зависание при входе в матч на серверах AWS во Франкфурте: игра подключается к серверу, но карта не загружается, и через пару минут игра возвращается в лобби. Провайдер пропускает примерно 25 первых UDP-пакетов соединения с зарубежным хостингом, а потом обрывает его.

Обход включен по умолчанию (`fake_stun = true`): перед первым пакетом каждого нового соединения игры с сервером матча (UDP, порты сервера 7000-7999) cleandns отправляет в это соединение один поддельный STUN-пакет. После него фильтр провайдера перестает обрывать соединение. Для этого исходящие пакеты к портам 7000-7999 проходят через cleandns без изменений, остальной трафик он не трогает.

Для этого нужен драйвер [WinDivert](https://github.com/basil00/WinDivert) 2.2.2. Он встроен в cleandns: при первом запуске рядом с exe появятся `WinDivert.dll`, `WinDivert64.sys` и `WinDivert-LICENSE.txt`, ничего скачивать не нужно. В логе будет строка `fake-stun: включен`, а при входе в матч - `fake-stun: подделка ...` с адресом сервера. Отключить обход можно в "Настройках": `fake_stun = false`.

WinDivert распространяется в неизменном виде по лицензии LGPLv3 (текст в `WinDivert-LICENSE.txt`). Существующие файлы WinDivert cleandns не перезаписывает, так что их можно заменить своей сборкой той же версии.

Кнопка "Выключить" в трее выключает и этот обход. WinDivert - драйвер для работы с сетевыми пакетами, его используют и другие программы обхода блокировок (zapret, GoodbyeDPI); некоторые антивирусы на него ругаются. Совместимость с античитом BattlEye проверена мало: в тестовых матчах проблем не было, но гарантировать это нельзя.

## Настройки

Файл `cleandns.toml` рядом с exe создается при первом запуске. Открыть его можно через меню "Настройки"; после сохранения изменения применяются сразу. Если в файле ошибка, cleandns покажет окно с ее описанием и продолжит работать со старыми настройками.

```toml
domains = ["playbattlegrounds.com"] # домены (со всеми поддоменами), для которых работает фильтр
dns = ["yandex-dot", "quad9-doh"]   # серверы, которые опрашиваются одновременно
fallback_dns = ["cloudflare-dot", "mullvad-dot", "controld-doh", "system"] # запасные; [] - не использовать
block = ["108.156.22.0/24"]         # подсети, адреса из которых никогда не выдавать
learn = true                        # самообучение
recheck = "6h"                      # как часто перепроверять найденные блокировки
fake_stun = true                    # обход обрыва UDP в матчах (см. выше)
fake_process = "TslGame"            # процесс игры, без .exe
fake_ttl = 64                       # TTL поддельного пакета, от 1 до 255
```

Готовые DNS-серверы для `dns` (doh - DNS over HTTPS, dot - DNS over TLS, без суффикса - обычный DNS):

| Провайдер | Варианты |
|---|---|
| Cloudflare | `cloudflare-doh`, `cloudflare-dot`, `cloudflare` |
| Google | `google-doh`, `google-dot`, `google` |
| Quad9 | `quad9-doh`, `quad9-dot`, `quad9` |
| AdGuard | `adguard-doh`, `adguard-dot`, `adguard` |
| Яндекс | `yandex-doh`, `yandex-dot`, `yandex` |
| Mullvad | `mullvad-dot` |
| ControlD | `controld-doh`, `controld` |
| OpenDNS | `opendns-doh`, `opendns` |
| DNS вашей сети | `system` |

Можно указать и свой сервер: `"https://имя/dns-query#IP"`, `"tls://IP#имя-из-сертификата"` или просто `"IP"`. Обычный DNS к зарубежным серверам провайдер или роутер часто перехватывает, поэтому для них лучше выбирать варианты `-doh` или `-dot`.

## Файлы рядом с exe

| Файл | Что это |
|---|---|
| `cleandns.toml` | настройки |
| `cleandns.log` | лог (очищается, когда становится больше 1 МБ) |
| `cleandns-state.txt` | подсети, найденные самообучением |
| `cleandns-switch.json` | сохраненные настройки DNS адаптеров, чтобы вернуть их при выключении |
| `WinDivert.dll`, `WinDivert64.sys`, `WinDivert-LICENSE.txt` | драйвер WinDivert для `fake_stun` и его лицензия, cleandns создает их сам |

## Предупреждение Windows

exe не подписан, поэтому при первом запуске скачанного файла Windows может показать окно "Система Windows защитила ваш компьютер". Нажмите "Подробнее", затем "Выполнить в любом случае".

## Удаление

Снимите галочку "Запускать при входе в Windows", выключите фильтр кликом по значку или выберите в меню "Выход" (DNS вернется к прежним настройкам), затем удалите папку. Драйвер WinDivert удалится из системы после перезагрузки.
